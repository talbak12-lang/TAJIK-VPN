TAJIK VPN — проект Android

Важно: это пока только демонстрационный экран. VPN-сервер WireGuard не настроен,
кнопка подключения отключена, поэтому приложение не передаёт интернет через VPN.

Как получить APK с телефона:
1. Войдите на GitHub и создайте новый пустой репозиторий.
2. Загрузите содержимое этой ZIP-архива в репозиторий (не сам ZIP-файл).
3. Откройте вкладку Actions. Если workflow ещё не запускался, разрешите Actions.
4. Выберите “Build TAJIK VPN APK” → “Run workflow”.
5. После успешного завершения откройте запуск и скачайте артефакт
   “TAJIK-VPN-debug-APK”. Внутри будет app-debug.apk.
6. Откройте APK на Android и разрешите установку из этого источника, если телефон спросит.

Для настоящего VPN нужно отдельно развернуть сервер и добавить интеграцию WireGuard
с VPNService/официальной библиотекой WireGuard. Этот проект сам по себе не является
рабочим VPN и не должен рекламироваться как такой.
